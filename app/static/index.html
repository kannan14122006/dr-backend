Diabetic retinopathy grading, as a service.

Upload a retinal fundus photograph and get its severity on the 5-level ICDR scale. Each response includes probabilities for every grade, a referable-DR verdict and a Grad-CAM heatmap that explains the decision.

Five severity levels

Every image gets one of the International Clinical DR (ICDR) grades. Grade 2 and above is referable: the patient should see an ophthalmologist.

Endpoints

All responses are JSON. CORS is enabled so any frontend can call the API directly.

POST/api/predictGrade a fundus image (multipart file). Returns the grade, probabilities, referable flag and Grad-CAM.Try in docs →
GET/api/healthService uptime, whether a model is loaded, architecture and device.Open →
GET/api/model/metricsValidation metrics, confusion matrix and per-epoch training history.Open →
GET/api/dataset/statsClass distribution, imbalance, image statistics and sample images.Open →
